# Study OS v3 — iPhone専用・追加費用0円

## 導入方法
1. このフォルダの `index.html`、`manifest.webmanifest`、`sw.js`、`icon.png`、`icon-512.png` をGitHubの公開リポジトリのルートへアップロードします。
2. GitHub → Settings → Pages → Deploy from a branch → main / (root) を選びます。
3. 発行されたHTTPS URLをiPhoneのSafariで開き、共有 → ホーム画面に追加。
4. 「設定」→「バックアップ」で毎週JSONを保存してください。自動同期・課金・Supabaseはありません。

**注意**: GitHub Pagesで公開する場合、アプリのソースコードは公開されます。個人の学習記録は端末内に保存され、GitHubに送信しません。GitHubへのバックアップJSONのアップロードは避けてください。

## 実装したもの
- 出社3日／リモート2日／土曜重点の時間割（曜日変更可能、日別例外設定）

- 月〜土に登録した予定と学習枠の**時刻の重なり**を検出し、通常予備→日曜08:00〜11:00へ必要な時間だけ再配置
- 日曜予定の保護、回収不能時間の表示
- 教材タスクを空き時間に割り当てた時間割の提示
- 学習タイマー、実績・正答率・理由の記録、復習待ち管理
- FAR講義27件（1〜6視聴済）、FAR論点別MCQ/TBSの暫定タスク、国徴理論49件・テーマ問題61件・過去問5件
- 週間レビュー、ChatGPT分析用JSON、全データのバックアップ・復元
- オフラインキャッシュ、ホーム画面アイコン
