# Knowledge OS（日経ビジネス知識ノート）

日経新聞などで学んだことを、日付・ジャンル別に記録、検索、復習するiPhone向け無料Webアプリです。

## 公開URL
GitHub Pagesをルートのmainブランチから配信している場合、 https://42dkp7m842-ui.github.io/study-os/knowledge-os/ でアクセスできます。

## 使い方
1. 朝刊から気になる記事を1本選び、「記録」で要点・背景・企業への影響・監査で考えられる点を自分の言葉で入力します。
2. 記録したらホームの当日チェックを付けます。
3. 「復習」から翌日・3日後・7日後・14日後・30日後・90日後の間隔で記憶を確認します。
4. 「知識庫」でジャンル別に検索し、履歴カレンダーで日付ごとの記録を確認します。
5. 週1回、右上の設定からJSONバックアップを保存します。CSV出力もできます。

## 保存と費用
完全無料。外部API・有料サービス・データベース契約なし。記録はブラウザ内のIndexedDBに保存され、GitHubへ自動送信されません。別ブラウザ・ホーム画面版とは自動同期しません。自動バックアップもないため、手動バックアップは必須です。機種変更・アプリ削除前にもJSONを保存してください。

新聞記事本文を転載せず、自分の言葉で要約してください。監査先の未公開情報や社内機密は記録しないでください。

## iPhoneのホーム画面に追加
Safariで公開URLを開き、共有メニューから「ホーム画面に追加」を選びます。初回接続後はオフライン閲覧にも対応します。
